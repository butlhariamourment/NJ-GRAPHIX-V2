NJ GRAPHIX V2 — ULTRA PREMIUM
==============================

FILES
- index.html: website structure
- css/style.css: all styling and responsive layout
- js/script.js: loader, particles, filtering, lightbox, navigation and animations
- assets/: add your portfolio images here

SETUP
1. Extract the ZIP.
2. Put your images in assets/ and name them cr2.jpg, cr3.jpg and cr4.jpg (or update the image paths in index.html).
3. Open index.html in a browser. For best results, use VS Code + Live Server.
4. Replace the placeholder email njgraphix@example.com with your real email.
5. Update the social links if needed.
